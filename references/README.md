# Referências externas

Índice do material externo que embasa o Shizune. Tudo aqui entra **apenas por link** — nenhuma cópia é vendorizada sem verificação prévia de licença, conforme a política de skills do framework (ver [CONTRIBUTING.md](../CONTRIBUTING.md)).

## Metodologia do pipeline

- **Matt Pocock — AI Hero**: <https://www.aihero.dev> — trabalho público que inspirou a metodologia do pipeline `grill-with-docs → domain-modeling → to-spec → implement → handoff` (atribuição registrada em [NOTICE](../NOTICE)). A licença de qualquer material dele deve ser verificada antes de vendorizar.

## Bibliotecas de skills de terceiros (fora do framework)

Bibliotecas vendor de skills de terceiros usadas em projetos de uma instância ficam **nos repositórios dos próprios projetos**, fora do framework, por política de licenciamento: licenças heterogêneas de terceiros não podem contaminar o pacote Apache 2.0. Elas entram aqui apenas **por referência**.

- **Curadoria de leitura sugerida** (skills públicas comuns nesses acervos): `systematic-debugging`, `tdd-workflow`, `clean-code`, `api-patterns`, `architecture`.
- O catálogo detalhado de cada acervo vendor pertence à ficha do projeto que o hospeda, na instância.
